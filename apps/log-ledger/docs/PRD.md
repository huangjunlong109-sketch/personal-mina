# LoG记账 - 产品需求文档

## 一、产品概述

### 1.1 产品定位
个人记账微信小程序，帮助用户记录日常收支、分析消费习惯。

### 1.2 目标用户
有记账习惯或想养成记账习惯的个人用户。

### 1.3 核心价值
- 快速记录收支（操作路径短）
- 清晰的分类统计与图表
- 灵活的账期设置（自定义每月起始日）

---

## 二、功能模块

### 2.1 底部导航（Tab Bar）

| Tab | 图标 | 说明 |
|-----|------|------|
| 明细 | 账单图标 | 首页，显示账单流水 |
| 图表 | 图表图标 | 统计分析 |
| 记账 | 加号（悬浮突出） | 快速记账入口 |
| 我的 | 头像图标 | 用户设置 |

---

### 2.2 明细页（首页）

**页面布局：**
- 顶部：当前年月选择器（可切换月份），显示当月收入/支出汇总
- 列表：按日期分组，每组显示当日支出/收入小计，每条记录显示分类图标、分类名、备注（可选）、金额

**交互：**
- 点击月份可左右切换
- 点击单条记录进入编辑/详情页
- 长按记录可删除

**账期说明：**  
"月"的定义由用户设置的每月起始日决定。例如起始日为 25 日，则 3/25 ~ 4/24 算作"3月"账期。

---

### 2.3 记账页

**触发方式：** 点击底部 Tab 中的「+」按钮弹出记账面板（底部弹起，半屏或全屏）

**页面布局：**
- 顶部 Tab：支出 / 收入切换
- 分类列表：图标+名称的网格布局（4列）
- 金额显示区：显示当前输入金额
- 备注输入：点击填写备注（选填）
- 日期选择：默认今天，可修改
- 数字键盘：自定义键盘（含小数点、退格、完成按钮）

**支出默认分类：**  
餐饮、住房、汽车、孩子、娱乐、人情、运动、通讯、社交、旅行、医疗、礼金、办公、主机、家用、露营、现金、交通、新年、设置（管理）

**收入默认分类：**  
工资、兼职、理财、礼金、其它、设置（管理）

**交互：**
- 选中分类高亮（黄色背景）
- 点击「完成」保存记录并关闭面板
- 点击「设置」进入分类管理页

---

### 2.4 图表页

**顶部：**
- 支出 ▼（可切换支出/收入）
- 周 / 月 / 年 三个维度切换

**周视图：**
- 上周 / 本周 切换
- 折线图：显示每天金额
- 总支出 + 平均值
- 支出排行榜（分类名、百分比、金额、进度条）

**月视图：**
- 折线图：显示每天金额（按账期）
- 总支出 + 日均值
- 支出排行榜

**年视图：**
- 折线图或柱状图：显示每月金额
- 年度总计
- 各月排行

---

### 2.5 分类管理页

**入口：** 记账页点击「设置」图标

**功能：**
- 查看支出/收入分类列表
- 长按排序（拖拽调整显示顺序）
- 点击分类可隐藏/显示（隐藏后记账页不展示，但历史记录保留）
- 新增自定义分类（名称 + 选择图标）
- 删除自定义分类（内置分类不可删除，只能隐藏）

---

### 2.6 我的页面

**功能列表：**
- 头像/昵称（微信授权）
- **账期设置**：每月从第 X 日开始（1-28，默认1日），影响明细月份分组和图表统计
- 分类设置（跳转分类管理页）
- 导出数据（导出当月或全部记录为表格，分享/保存）
- 关于

---

## 三、非功能需求

| 项目 | 要求 |
|------|------|
| 数据隔离 | 每个用户只能访问自己的数据（openid 隔离） |
| 离线友好 | 列表数据本地缓存，网络恢复后同步 |
| 响应速度 | 记账操作完成后 < 500ms 反馈 |
| 金额精度 | 支持小数点后2位，存储单位为分（整数）|
